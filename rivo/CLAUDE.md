# Rivo – כלי לניטור מתחרים לעסקים קטנים ובינוניים בישראל

## מה זה
Rivo עוקב אוטומטית אחרי המתחרים של עסק (מודעות, מחירים, אתר, ניוזלטרים, רשתות, ביקורות, SEO),
ומתרגם את זה לסיכום קצר בעברית ול"מה לעשות השבוע". ההתראות מגיעות במייל ובוואטסאפ.

- **קהל יעד:** בעלי עסקים קטנים ובינוניים בישראל, בלי איש שיווק צמוד.
- **השראה לממשק:** Panoramata – קליל, נקי, הכול במקום אחד. לא להעתיק מיתוג או טקסטים.
- **היתרון שלנו:** עברית מלאה ו-RTL, וואטסאפ, המלצות פעולה ולא רק נתונים, תשלום בשקלים עם חשבונית.

## מצב נוכחי
`index.html` הוא אב-טיפוס פרונט מלא, קובץ אחד, HTML/CSS/JS בלי תלויות, עם נתוני דמה.
פותחים אותו ישירות בדפדפן. הניווט עובד לפי `#hash` (למשל `index.html#ads`, `#welcome` להרשמה).
**המשימה הבאה:** להפוך אותו לאפליקציה אמיתית תוך שמירה על העיצוב והטקסטים.

## מסכים באב-טיפוס
| נתיב | מסך |
|---|---|
| `#welcome` | הרשמה ב-3 שלבים: אתר → בחירת מתחרה (בניסיון: אחד) → ערוצי התראה |
| `#home` | "מה לעשות השבוע", ציון חודשי, פיד עדכונים עם סינון לפי ערוץ |
| `#competitors`, `#competitor/:id` | רשימת מתחרים, מתחרים שנמצאו אוטומטית, פרופיל מתחרה |
| `#ads` | ספריית מודעות (מטא, גוגל), סינון "רצה 30+ יום" |
| `#prices` | שינויי מחיר מול המחיר של הלקוח, מבצעים פעילים |
| `#site` | שינויים באתר (לפני/אחרי) |
| `#inbox` | ניוזלטרים ו-SMS של מתחרים |
| `#social` | רשתות אורגניות: תדירות, מעורבות, פוסט מוביל |
| `#reviews` | דירוגים, נושאים חוזרים בביקורות, שינויים בפרופיל גוגל העסקי |
| `#seo` | מיקומי מילות מפתח: הלקוח מול המתחרים |
| `#score` | ציון חודשי והשוואה לעסק של הלקוח |
| `#chat` | צ'אט עם הנתונים (גם בוואטסאפ) |
| `#inspiration` | ספריית השראה עם תגיות |
| `#reports` | הפקת דוח PDF |
| `#alerts` | הגדרות התראות: מייל, וואטסאפ, יומי/שבועי, התראות מיידיות |
| `#team`, `#billing`, `#referral` | צוות והרשאות, מנויים, חבר מביא חבר |

## פיצ'רים שסוכמו
**ליבה:** ניהול מתחרים · מעקב מודעות (Meta Ad Library, Google Ads Transparency Center) · מחירים ומבצעים ·
שינויים באתר · סיכום AI בעברית · התראות במייל ובוואטסאפ · לוח בקרה.

**שלב שני:** רשתות אורגניות · ביקורות בגוגל · SEO · השוואה לעסק של הלקוח · גילוי מתחרים אוטומטי · דוח PDF.

**תוספות:** "מה לעשות השבוע" · ניוזלטרים ו-SMS · פרופיל גוגל עסקי · הרשמה בשתי דקות · ספריית השראה ·
צ'אט עם הנתונים (גם בוואטסאפ) · ציון חודשי · ניסיון חינם עם מתחרה אחד · חבר מביא חבר.

**מערכת:** משתמשים וצוותים · מנוי לפי מספר מתחרים · איסוף מידע ציבורי בלבד.

**הוחלט לא לכלול:** מענה מהיר למהלך מתחרה, ניתוח מסרים, לוח חגים, תנאי מכירה, מודעות דרושים.

## המלצה לסדר בנייה
1. **MVP:** הרשמה, מתחרים, מודעות, מחירים, שינויים באתר, סיכום AI, התראות מייל + וואטסאפ, ניסיון חינם.
2. ניוזלטרים/SMS, צ'אט, ציון חודשי, ספריית השראה.
3. רשתות, ביקורות ופרופיל גוגל, SEO, דוחות PDF, צוותים, חבר מביא חבר.

## סטאק (אושר מול המשתמש)
- פרונט: Next.js + TypeScript + Tailwind (עם RTL), להעביר את העיצוב מ-`index.html` לרכיבים.
- בקאנד ומסד נתונים: Supabase (Postgres + Auth) או חלופה דומה.
- איסוף: עובדים מתוזמנים (cron/queue) לסריקת אתרים והשוואת גרסאות, API של ספריית המודעות של מטא.
- AI: Claude API לסיכומים, "מה לעשות השבוע" והצ'אט.
- התראות: WhatsApp Business API (דרך ספק BSP), מייל דרך ספק טרנזקציוני.
- תשלומים: ספק סליקה ישראלי עם הפקת חשבוניות.
- המשתמש עובד על Windows.

## עיצוב
- צבעים: רקע `#F3F5F7`, טקסט `#16202A`, מותג (טורקיז) `#0F766E`, הדגשה (צהוב) `#FFC83D`, התראה `#D93F45`. מצב כהה מוגדר ב-CSS.
- פונטים: Fredoka לכותרות ולוגו, Assistant לטקסט (Google Fonts, תומכים בעברית).
- `dir="rtl"`, שימוש ב-logical properties (`inset-inline-start` וכו').
- רספונסיבי: בטלפון התפריט הצדדי נפתח כמגירה.
- כרטיס "מה לעשות השבוע" הוא האלמנט הבולט במסך. כל השאר שקט.
- כפתורים כתובים בפעולה ברורה ("הוספת מתחרה", "הפקת PDF"), בעברית פשוטה.
