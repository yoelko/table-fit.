# מקור האפליקציה

- `room-fit.html` – קוד המקור היחיד של האפליקציה.
- `python3 build.py <גרסה>` – בונה את האפליקציה החיה (index.html בשורש).
- `python3 build.py <גרסה> preview` – בונה את גרסת הניסיון ב-`preview/` (נתונים נפרדים מהאפליקציה החיה).
- `playon-products.json` – הקטלוג שנאסף מ-playon.co.il.
- קובצי `*.py` – בדיקות Playwright.
